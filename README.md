# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

##### Данные
   Класс ProductCatalog
    Класс отвечает за хранение и управление списком товаров, полученных с сервера, а также за выбор товара для предварительного просмотра.
    Данные:
        items: T[] — массив объектов товаров.
        selectedProduct: T — товар, выбранный для открытия в модальном окне.
    Методы:
        setItems(items: T[]): void — сохраняет массив товаров в модели.
        getItems(): T[] — возвращает копию текущего массива товаров.
        getProductById(id: string): T — ищет товар в каталоге по его уникальному идентификатору.
        setSelected(product: T): void — сохраняет товар для детального отображения.
        getSelected(): T — возвращает выбранный товар.
    Класс ProductBasket
        Класс управляет состоянием корзины: хранением выбранных товаров, их удалением и расчетом итоговой стоимости.
        Данные:
            items: IProduct[] — массив объектов уникальных товаров, добавленных в корзину.
        Методы:
            getItems(): IProduct[] — возвращает массив всех товаров, находящихся в корзине.
            addItem(product: IProduct): void — добавляет товар в корзину, если он еще не был в неё добавлен (товары хранятся в одном экземпляре).
            removeItem(productId: string): void — удаляет товар из корзины по его уникальному идентификатору.
            clear(): void — полностью очищает корзину (используется после успешного оформления заказа).
            getTotal(): number — возвращает общую сумму стоимости всех товаров в корзине.
            getCount(): number — возвращает количество товаров в корзине (длину массива).
            hasItem(productId: string): boolean — проверяет наличие товара в корзине по его ID.
    Класс Buyer
        Класс хранит персональные данные покупателя и отвечает за их валидацию перед отправкой заказа.
        Данные:
            data: IBuyer — объект с полями: способ оплаты, адрес, телефон и email.
        Методы:
            save(data: Partial<IBuyer>): void — обновляет данные покупателя (можно передать только часть полей).
            saveField(field: keyof IBuyer, value: string): void — обновляет конкретное поле данных.
            getAll(): IBuyer — возвращает текущий объект данных покупателя.
            clear(): void — сбрасывает все данные (очищает поля).
            validateField(field: keyof IBuyer): object — проверяет конкретное поле на заполненность, возвращает статус и текст ошибки.
            validateAll(): object — проводит полную проверку всех данных покупателя. Возвращает общий статус валидности и список найденных ошибок.
###### Слой коммуникации 
    Класс AppApi
    Наследует класс Api или использует его методы для взаимодействия с сервером магазина.
    Конструктор:
        constructor(cdn: string, baseUrl: string, options?: RequestInit) — принимает базовый URL, URL для контента (изображений) и настройки запроса.
    Методы:
        getProductList(): Promise<IProduct[]> — получает массив товаров с сервера.
        orderProducts(order: IOrder): Promise<IOrderResult> — отправляет данные о заказе и выбранных товарах на сервер, возвращает результат оплаты.
###### Слой представления
        1. Базовые классы
            Класс Component<T>
                Основа для всех UI-компонентов. Содержит инструментарий для работы с DOM.
                Методы:
                render(data?: Partial<T>): HTMLElement — заполняет данными и возвращает корневой элемент.
                setText(element: HTMLElement, value: string) — устанавливает текстовое содержимое.
                setDisabled(element: HTMLElement, state: boolean) — меняет статус активности.
                setImage(element: HTMLImageElement, src: string, alt?: string) — устанавливает изображение.
            Класс Modal
                Универсальное модальное окно. Управляет открытием/закрытием и сменой контента.
                Данные: Кнопка закрытия, контейнер для контента.
                Методы:
                open() / close() — управление видимостью.
                set content(value: HTMLElement) — замена содержимого в .modal__content.
                События: modal:open, modal:close.
        2. Работа с формами
            Класс Form<T> (родитель)
                Управляет валидацией и отображением ошибок.
                Данные: Кнопка сабмита, элемент для текста ошибок.
                Методы:
                    onInputChange(field: string, value: string) — генерирует событие при вводе.
                    set valid(value: boolean) — управляет активностью кнопки «Далее/Оплатить».
                    set errors(value: string) — устанавливает текст ошибки.
                    События: [formName]:submit, [formName]:input.
            Класс OrderForm (дочерний от Form)
                Реализует форму выбора оплаты и ввода адреса.
                Методы:
                    set payment(name: string) — переключает активную кнопку оплаты (Онлайн/Наличные).
                Класс ContactsForm (дочерний от Form)
                    Реализует форму ввода Email и Телефона.
        3. Работа с карточками товара
            Класс Card (родитель)
                Общий функционал для всех типов карточек.
                Данные: Заголовок, цена.
            Класс CardCatalog (дочерний от Card)
                Карточка для главной страницы (#card-catalog).
                Данные: Категория, изображение.
                События: card:select (клик по карточке).
            Класс CardPreview (дочерний от Card)
                Детальное описание товара в модальном окне (#card-preview).
                Данные: Категория, изображение, текст описания, кнопка «В корзину».
                События: card:add (нажатие кнопки покупки).
            Класс CardBasket (дочерний от Card)
                Элемент товара в списке корзины (#card-basket).
                Данные: Индекс (номер в списке), кнопка удаления.
                События: card:remove (нажатие на «корзину» удаления).
        4. Остальные компоненты
            Класс Basket
                Отображение содержимого корзины (#basket).
                Данные: Список (ul), итоговая стоимость, кнопка «Оформить».
                Методы:
                set items(items: HTMLElement[]) — обновляет список карточек.
                set total(value: number) — обновляет итоговую цену.
                События: basket:order (нажатие на кнопку оформления).
            Класс Page
                Управляет главной страницей: галереей и счетчиком корзины.
                Данные: Счетчик в хедере, контейнер .gallery, обертка .page__wrapper (для блокировки прокрутки).
                Методы:
                set counter(value: number) — обновляет цифру на кнопке корзины.
                set gallery(items: HTMLElement[]) — наполняет главную страницу карточками.
                set locked(value: boolean) — блокирует скролл страницы (при открытии модалки).
                События: basket:open.
            Класс Success
                Экран успешного оформления (#success).
                Данные: Сумма списания, кнопка закрытия.
                События: success:close.

        Слой управления (Presenter / Скрипт main.ts)

        1. Инициализация приложения
                При запуске скрипта выполняются следующие действия:
                Создаются экземпляры базовых сервисов: EventEmitter (брокер событий) и AppApi (работа с сервером).
                Инициализируются модели данных: ProductCatalog, ProductBasket и Buyer, в которые передается брокер событий.
                Создаются основные компоненты интерфейса: Page (главная страница) и Modal (контейнер для окон).
                Подготавливаются (клонируются из шаблонов) формы заказа и корзина.
        2. Обработка событий взаимодействия (Логика)
                Презентер слушает события, генерируемые компонентами представления или моделями, и вызывает соответствующие действия:
                События каталога и товаров:
                items:changed: Срабатывает при обновлении списка товаров в модели. Презентер формирует массив карточек CardCatalog и передает их в page.catalog для отрисовки.
                card:select: Срабатывает при клике на карточку. Презентер запрашивает данные о товаре и открывает модальное окно с компонентом CardPreview.
                card:toBasket: Срабатывает при нажатии кнопки «В корзину». Презентер добавляет товар в модель корзины.
            События корзины:
                basket:open: Открывает модальное окно с текущим содержимым корзины (basketView).
                basket:changed: Срабатывает при любом изменении в корзине. Презентер обновляет счетчик на главной странице и перерисовывает список товаров в открытом окне корзины.
                card:remove: Удаляет товар из модели корзины по его ID.
            События оформления заказа (Forms):
                order:open: Открывает первую форму оформления (выбор оплаты и ввод адреса).
                (order|contacts).*:change: Срабатывает при вводе данных в поля форм. Презентер передает данные в модель Buyer для сохранения и мгновенной валидации.
                buyer:changed: Реагирует на изменения данных покупателя. Презентер обновляет статус кнопок (валидность) и выводит тексты ошибок в соответствующие формы.
                order:submit: Переключает модальное окно на вторую форму (контакты).
                contacts:submit: Собирает финальный объект заказа (данные покупателя + ID товаров + сумма) и отправляет его на сервер через api.orderProducts.
            События системы:
                modal:open: Блокирует прокрутку основной страницы (добавляет класс page__wrapper_locked).
                modal:close: Разблокирует прокрутку страницы.
        3. Завершение заказа
                При успешном ответе от сервера:
                    Вызывается метод clear() у моделей корзины и покупателя.
                    Счетчик корзины на странице сбрасывается в 0.
                    Открывается модальное окно с компонентом Success, уведомляющее пользователя об успешной покупке.
